# Code of conduct

This repository is a technical project: modules, ports, firmware analysis,
docs. Conduct that applies in issues, pull requests, reviews and any
discussion of the project:

- Keep to the work: what a change does, what was measured, what would falsify it.
- Credit authors. A module is credited to the person who wrote it; do not remove or rewrite credit.
- No harassment, personal attacks, or posting someone's private information.
- Review comments are about the code and the claims in the PR.
- Do not post Elektron firmware or images (`CONTRIBUTING.md`).

A maintainer may edit or remove a comment, close an issue or PR, or block an
account that breaks these. Report a conduct problem privately through the
repository's **Security** tab ("Report a vulnerability"), or by
@-mentioning a maintainer on the thread if it is not sensitive.
