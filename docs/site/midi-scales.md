# MIDI Scales

The optional MIDI Scales module extends the native MIDI ARP SETUP KEY control
to seven modes in all twelve keys. Open FUNC + AMP, then use encoder F.
OFF and original Major/Minor IDs retain their meaning; extra choices are saved
in the existing Part field. Set KEY to OFF or an original choice before moving
an edited Part to stock firmware. Audio-track Scale Quantizer is independent.

The standalone `midi-scales` test remix selects this module with stock effects.
The `octabam-bus` user remix is unchanged. Source and linked-code checks are
documented beside the module; physical hardware acceptance is still pending.

See the [MIDI Scales controls and LCD examples](reference/modules/midi-scales.md)
for the step-by-step workflow.
